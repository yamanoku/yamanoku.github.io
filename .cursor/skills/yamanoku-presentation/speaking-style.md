# 喋り口調と原稿の書き方

## 口調

- **丁寧体の話し言葉**: 「〜です／ます」「〜と思います」「〜でしょう」「〜していきます」。だ・である調は見出しと強調句だけに使う
- **一人称**: 「私」。経験談の節では「私自身も」。
- **呼びかけ**: 「皆さん」。修辞疑問で間を作る（「〜でしょうか？」「明確に答えられるでしょうか？」）
- **断定と推奨**: 主張ははっきり言い切る（「やめましょう」「お勧めします」「誤解を恐れずに言うと」）一方で、否定しすぎない（「使ってはいけないと言いたいわけではありません」）
- **ユーモアは軽く**: 自虐（「私もその1人です」）、地元ネタ（「物理船橋市民ではなく論理船橋市民」）、一句。絶対に煽りはしない
- 絵文字は原稿本文では使わない

## 定型フレーズ

| 場面 | フレーズ |
|---|---|
| 開始 | 「皆さん、〇〇ですか？」「突然ですが、みなさんは〜」 |
| 自己紹介 | 「最初に自己紹介をさせてください」「yamanokuと申します」「改めてよろしくお願いいたします」 |
| 前提 | 「本題に入る前に、前提を揃えたいと思います」 |
| 本題へ | 「それでは今回の本題でもある〜」「さて」「ここからは、私自身の経験を〜」 |
| 段取り | 「順に説明していきましょう」「一緒に見てみましょう」「まず」「次に」「一方で」「というわけで」「まとめです」 |
| 問いかけ | 「本当にそのままでよいのでしょうか？」「おや、これでおしまいでしょうか」「分かりましたでしょうか」 |
| 呼びかけ | 「明日からの開発に生かしていただけると」「まずはやってみて、残してみよう」「調べてみるとよいかもしれません」「今日の発表がきっかけになれば」 |
| 連帯 | 「続けていきましょう」「共に作っていきましょう」 |
| 締め | 「以上で発表を終わります。ご清聴いただきありがとうございました。」 |

フレーズは定型句の在庫として使う。毎回すべて入れない。

## 引用・根拠の示し方

- 本文中のインラインリンク ＋ 末尾の `## 参考文献` に正式タイトル付きで列挙する
- 英語仕様は原文を `>` で引用し、直後に（日本語訳）を添える
- 補足リンクは脚注 `[^1]`（markdown-it-footnote が有効）
- 図には `<figure>` と `<figcaption>出典：…</figcaption>` を付ける
- 生成AIを使った場合やレビュワーがいる場合は `## 謝辞` を参考文献の前に置く

## 原稿 Markdown の型

```markdown
---
layout: layout
title: タイトル
subtitle: サブタイトル（任意）
description: {イベント名}のyamanokuの発表資料
lang: ja
---

![スライドタイトル：（スライドに書かれている内容の説明）](images/title.png)

## スライド

https://records.yamanoku.net/{name}/slide/

## はじめに

…

## 参考文献

- [正式タイトル](URL)
```

- 見出しは `##` が章、`###` が節。`h1` は layout が `title` から出すので書かない
- 多言語版のページには冒頭に `[日本語](../ja/) / [English](../en/)` のような相互リンクを置く
- 余談・おことわりは `<article>` で囲む
- 動画デモは `<video src="…" controls>`。インラインの `style` 属性は使わない
- コードは悪い例 → 良い例の順に並べる

## 多言語版

ja を正として、en / ko は見出し構成と画像を一致させて訳す。frontmatter の `lang` を各言語にする。スライドは日本語のみで作り、intro スライドに各言語のドキュメントページへのリンクを置く。
